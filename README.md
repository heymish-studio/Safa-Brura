# שפה ברורה · Safa Brura — תיקון אוטומטי של עברית/אנגלית במקלדת

**[⬇ הורדה: SafaBrura.exe](https://github.com/heymish-studio/Safa-Brura/releases/latest/download/SafaBrura.exe)**
(קובץ אחד, בלי התקנה. Windows 10/11 עם עברית מותקנת כשפה. בהפעלה הראשונה SmartScreen יציג אזהרה כי הקובץ לא חתום: לחץ "מידע נוסף" ואז "הפעל בכל זאת".)

בהפעלה הראשונה נפתח חלון הסבר קצר עם אפשרות "הפעל אוטומטית בכל כניסה לווינדוס". אפשר לפתוח אותו שוב מתפריט האייקון במגש ("הסבר קצר").

אפליקציית מגש (tray) קטנה לווינדוס. היא עוקבת אחרי המילה שאתה מקליד, וברגע שאתה מסיים אותה
(רווח, Enter, סימן פיסוק) היא בודקת: המילה הזו ג'יבריש בשפה הנוכחית, אבל מילה אמיתית ונפוצה
בפריסה השנייה? אם כן, היא מוחקת את המילה, מקלידה אותה מחדש בשפה הנכונה, ומחליפה את פריסת
המקלדת כדי שההמשך ייכתב נכון.

דוגמה: הקלדת `akuo` ורווח כשהמקלדת באנגלית → הופך ל-`שלום`, והמקלדת עוברת לעברית.
הקלדת `יקךךם` ורווח כשהמקלדת בעברית → הופך ל-`hello`, והמקלדת עוברת לאנגלית.

## איך זה מחליט (ולמה זה לא משגע אותך)

- **לא נוגעים במילה תקינה.** המילה שהוקלדה נבדקת בצורה סלחנית מול רשימת תדירות של 50 אלף מילים
  ומול בודק האיות המובנה של ווינדוס. אם היא סבירה בשפה שבה הוקלדה, לא קורה כלום.
- **מתקנים רק למילה נפוצה.** המילה המומרת חייבת להופיע ברשימת התדירות של השפה השנייה (ברירת מחדל:
  לפחות 200 מופעים בקורפוס, ומילים של שתי אותיות דורשות 5,000), ולעבור כללי צורה (אותיות סופיות
  בעברית רק בסוף מילה, גרש רק אחרי ג/ז/צ/ת/ד).
- **מדידה על הרשימות עצמן** (`python test_engine.py`): 0 תיקוני-שווא על מילים נכונות, כ-94%
  מהמילים הנפוצות מתוקנות, וכ-1.5% מהטעויות הקלדה באנגלית מומרות בטעות לעברית. לזה יש ביטול.
- **משפט אחד, שפה אחת.** מילים קצרות כמו "אם" (`to`), "גם" (`do`) או "עם" (`go`) הן מילים תקינות בשתי השפות, ולבד הן לא מעידות על טעות.
  ברגע שמילה אחרת במשפט מתוקנת, כל מה שהוקלד מתחילת המשפט עובר איתה לאותה שפה. משפט קודם שהסתיים בנקודה, וצירופים שלא
  יוצאים מילה תקינה בשפה השנייה (כמו `ok`), נשארים כמו שהם.
- **מילים שלא נתפסו** (למשל `של` שהוקלד כ-`ak`, שנראה כמו אנגלית) מתקנים ידנית במקש אחד.

## המרה ידנית וביטול

| מקש | פעולה |
|---|---|
| `Shift+Backspace` או `Pause` | ממיר את המילה האחרונה לפריסה השנייה. אם נלחץ **מיד אחרי תיקון אוטומטי**, זה מבטל את התיקון ושומר את המילה ברשימת החרגה כדי שלא תתוקן שוב |
| `Ctrl+Shift+Backspace` או `Shift+Pause` | ממיר את כל מה שהוקלד מאז הלחיצה/Enter האחרונים (מילים שכבר תוקנו אוטומטית נשארות) |

במחשבים ניידים רבים אין מקש Pause, ולכן Shift+Backspace הוא ברירת המחדל הראשונה. אפשר לשנות ב-`config.json`
(`"hotkeys": ["shift+backspace", "pause"]`, `"hotkeys_all": [...]`; למשל `"f12"` או `"ctrl+shift+space"`).

## איפה זה לא עובד בכוונה

- **שדות סיסמה** — מזוהים דרך UI Automation ולא נוגעים בהם.
- **טרמינלים** (cmd, PowerShell, Windows Terminal) ו-**אפליקציות גישה מרחוק / מנהלי סיסמאות**
  (mstsc, AnyDesk, TeamViewer, KeePass, 1Password, Bitwarden...) — מוחרגים דרך ההגדרות.
- מילים שמכילות ספרות, וכל דבר שמוקלד עם Ctrl/Alt/Win.

## הפעלה

**מקוד המקור** (Python 3.10+):

```
pip install -r requirements.txt
run.bat
```

או **קובץ exe יחיד**: `build.bat` יוצר את `dist\SafaBrura.exe` (דורש `pip install pyinstaller`).

אחרי ההפעלה מופיע אייקון כחול `Aא` במגש. לחיצה ימנית:

- **תיקון אוטומטי פעיל** — כיבוי/הדלקה (המקש הידני עובד תמיד).
- **הפעלה עם ווינדוס** — יוצר קיצור בתיקיית Startup.
- **הסבר קצר** / **דף התוכנה באינטרנט** — חלון ההסבר של ההפעלה הראשונה, והדף הזה.
- **פתח קובץ הגדרות** / **פתח יומן** — `%APPDATA%\SafaBrura\config.json` ו-`log.txt`.

## הגדרות (`%APPDATA%\SafaBrura\config.json`)

| שדה | ברירת מחדל | משמעות |
|---|---|---|
| `enabled` | `true` | תיקון אוטומטי |
| `min_word_len` | `2` | אורך מילה מינימלי לתיקון אוטומטי |
| `min_target_count` | `200` | כמה נפוצה המילה המומרת צריכה להיות (עלה ל-1000 אם יש יותר מדי תיקוני-שווא) |
| `min_short_count` | `5000` | אותו דבר למילים של 2 אותיות |
| `beep_on_fix` | `true` | צפצוף קצר בכל תיקון |
| `hotkeys` / `hotkeys_all` | `["shift+backspace","pause"]` / `["ctrl+shift+backspace","shift+pause"]` | מקשי ההמרה הידנית (מילה אחרונה / הכול) |
| `fallback_switch_hotkey` | `"alt+shift"` | אם החלפת הפריסה דרך הודעת ווינדוס נכשלת, מדמים את קיצור ההחלפה הזה |
| `excluded_processes` / `excluded_window_classes` | ראה קובץ | איפה לא לגעת |
| `ignore_words` | `[]` | מילים שלא יתוקנו אוטומטית (מתמלא לבד בביטולים) |

## קבצים

- `autolang.py` — האפליקציה: hook מקלדת ועכבר, ביצוע התיקון, מגש, הגדרות, הפעלה עם ווינדוס.
- `welcome.py` — חלון ההסבר של ההפעלה הראשונה (דיאלוג מקורי של ווינדוס, מימין לשמאל).
- `engine.py` — ההחלטה: רינדור מקשים דרך פריסות, רשימות תדירות, כללי צורה.
- `spellcheck.py` — עטיפה לבודק האיות המובנה של ווינדוס (COM, בלי מילונים חיצוניים).
- `winapi.py` — Win32: פריסות, SendInput, חלון ממוקד, UI Automation.
- `data/he_50k.txt`, `data/en_50k.txt` — רשימות תדירות (פרויקט FrequencyWords, כתוביות OpenSubtitles 2018).
- `test_engine.py` — מדידת דיוק בלי מקלדת. `test_sentence.py` — סימולציה של התוכנה על מסך וירטואלי, בלי מקשים אמיתיים. `test_e2e.py` — בדיקה אמיתית עם הקלדה מדומה (להריץ רק כשאף אחד לא משתמש במחשב).

## מגבלות ידועות

- העברת טקסט ל-Notepad הישן של Windows 11, Word וכו' עובדת; אפליקציות שמשנות טקסט בעצמן (השלמה אוטומטית
  אגרסיבית) עלולות לקבל תיקון חלקי. במקרה כזה `Pause` מסדר.
- Enter אחרי מילה שגויה: המילה מתוקנת לפני ששורת ה-Enter נשלחת, כך שבצ'אטים ההודעה יוצאת נכונה.
- עובד עם כל זוג פריסות מותקנות שיש להן קובץ `data/<lang>_50k.txt`; כרגע מצורפים עברית ואנגלית.
